# ROUJLA AI

مساعد ذكاء اصطناعي عربي جاهز للنشر على **GitHub Pages**، بدون خادم وبدون تسجيل.
يجيب على أسئلة الزوار، يشرح، يكتب، يبرمج، ويساعد في التخطيط، مع واجهة عربية/إنجليزية
ووضع فاتح/داكن وحفظ المحادثات في المتصفح.

```
الاسم     : ROUJLA AI
النوع     : صفحة ثابتة (HTML + CSS + JavaScript)
الاستضافة : GitHub Pages
المزوّد   : Pollinations AI (مجاني، بدون مفتاح) أو أي API متوافق مع OpenAI
```

## الملفات

```
index.html              الواجهة الكاملة
styles.css              التصميم (فاتح/داكن، RTL/LTR، جوال)
config.js               الإعدادات الافتراضية، الترجمات، الأسئلة المقترحة
app.js                  الحالة، التخزين المحلي، عرض المحادثات، الأحداث
chat.js                 طلبات النموذج، الإرسال، إعادة التوليد، معالجة الأخطاء
icon.svg                شعار الموقع (SVG)
icon-192.png            أيقونة PWA 192
icon-512.png            أيقونة PWA 512
apple-touch-icon.png    أيقونة iOS
og.png                  صورة المشاركة الاجتماعية 1200×630
manifest.webmanifest    بيانات تطبيق الويب
GenerateAssets.ps1      إعادة توليد الأيقونات والصور
```

## التجربة محلياً

من مجلد الموقع:

```powershell
python -m http.server 8765
```

ثم افتح `http://127.0.0.1:8765/`.

> لا تفتح `index.html` مباشرة بنقرة مزدوجة إن أمكن؛ بعض المتصفحات تقيّد الطلبات
> من بروتوكول `file://`. التشغيل عبر خادم محلي يعطي نتيجة مطابقة لـ GitHub Pages.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً باسم `roujla-ai` في حسابك `ABDELKARIM-LAITAR`.
2. ارفع كل ملفات هذا المجلد إلى الفرع `main` (بدون مجلد إضافي).
3. من المستودع: **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** — Folder: **/ (root)**
4. انتظر دقيقة، ثم سيكون الرابط:

```
https://abdelkarim-laitar.github.io/roujla-ai/
```

إذا اخترت اسماً آخر للمستودع، غيّر الرابط في موقع محرك البحث (انظر أسفل).

## كيف يعمل الذكاء الاصطناعي بدون خادم؟

الصفحة تستدعي واجهة **Pollinations AI** المجانية والمتوافقة مع OpenAI:

```
POST https://text.pollinations.ai/openai
```

- لا يحتاج الزائر إلى تسجيل أو مفتاح.
- الطلب يذهب مباشرة من متصفح الزائر إلى الخدمة (CORS مفتوح).
- النموذج الافتراضي `openai`، وبديله `openai-fast` عند الازدحام.
- عند خطأ 402/429 تُجرَّب النماذج البديلة تلقائياً، ثم تظهر رسالة عربية واضحة.

هذه خدمة مجانية تابعة لطرف ثالث، وقد تتغير حدودها أو تتوقف. للإنتاج الجاد يمكن
استخدام مزوّد مدفوع من إعدادات الموقع (بدون تعديل الكود).

## استخدام API خاص (اختياري)

من زر **الإعدادات**:

1. اختر **واجهة API خاصة**.
2. أدخل اسم النموذج (مثل `gpt-4o-mini`).
3. أدخل عنوان API (مثل `https://api.openai.com/v1`).
4. أدخل مفتاح API.

يُخزَّن المفتاح في `localStorage` داخل متصفح الزائر فقط، ولا يُرسل إلا إلى العنوان
الذي أدخله. يجب أن يسمح الخادم بطلبات المتصفح (CORS)، وإلا سيفشل الطلب.

> لا تضع مفتاحاً خاصاً بك داخل الكود أو المستودع؛ أي مفتاح داخل صفحة عامة يصبح
> مكشوفاً للجميع.

## الخصوصية والبيانات

- المحادثات تُحفظ في `localStorage` داخل متصفح الزائر فقط.
- لا يوجد خادم خاص بنا ولا قاعدة بيانات ولا حسابات.
- نص السؤال (وسياق المحادثة) يُرسل إلى مزوّد الذكاء الاصطناعي لمعالجته.
- زر **حذف كل البيانات** يمسح المحادثات والإعدادات من المتصفح.
- لا تشارك معلومات شخصية أو حساسة في الأسئلة.

## تخصيص سريع

## الخطة المستقبلية: دومين roujla.com

البنية الصحيحة للنطاقات الفرعية:

```
www.roujla.com   → الموقع الرئيسي (محرك البحث roujla)
ai.roujla.com    → ROUJLA AI
soft.roujla.com  → ROUJLA SOFT
```

> تصحيح مهم: `www.roujla.soft.com` ليست نطاقاً فرعياً لـ `roujla.com`، بل نطاق
> تحت `soft.com` (الذي لا نملكه). الصيغة الصحيحة هي `soft.roujla.com`، وكذلك
> `ai.roujla.com` وليس `www.roujla.ai.com`.

**الكود جاهز مسبقاً:** الروابط تُختار تلقائياً حسب اسم النطاق الذي يُفتح منه الموقع
(دالة `siteFamily` في `config.js`، و`SITES` في صفحة محرك البحث). عند ربط الدومين
ستنتقل الروابط وحدها من `github.io` إلى `roujla.com` دون تعديل أي سطر.

### خطوات الربط عند شراء الدومين (Cloudflare)

1. أضف السجلات التالية في Cloudflare DNS مع **Proxy = DNS only** (سحابة رمادية):

| النوع | الاسم | القيمة |
|---|---|---|
| CNAME | `ai` | `abdelkarim-laitar.github.io` |
| CNAME | `soft` | `abdelkarim-laitar.github.io` |
| CNAME | `www` | `abdelkarim-laitar.github.io` |
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |

2. في كل مستودع على GitHub: **Settings → Pages → Custom domain**، اكتب النطاق،
   ثم فعّل **Enforce HTTPS**.
3. انسخ ملف `CNAME.example` إلى `CNAME` (بعد حذف `.example`) ليحتوي نطاق المستودع:
   - `roujla-ai` → `ai.roujla.com`
   - `roujlasoft` → `soft.roujla.com`
   - `roujla` → `www.roujla.com`
4. لا تفعّل Proxy البرتقالي مع GitHub Pages (يسبب أخطاء شهادة/إعادة توجيه).
5. بعد نجاح الربط، حدّث `og:image` في `index.html` إلى رابط مطلق
   (`https://ai.roujla.com/og.png`) لأن شبكات التواصل لا تقرأ الروابط النسبية.
